# TakeSmart Station — установка приложений на iPhone покупателя

Программа для Mac в павильоне. Делает то же, что сервисы вроде bmrng: подключаем
iPhone покупателя кабелем, покупатель входит в свой Apple ID, и мы ставим ему
всё, что когда-либо было в истории покупок этого аккаунта — банки, соцсети,
мессенджеры, которых уже нет в App Store. Приложения скачиваются оригинальным
файлом Apple под учётку покупателя, поэтому никаких сертификатов и «слётов»
через неделю.

## Что нужно один раз

1. Mac с macOS 13+ и Homebrew.
2. Утилиты:

       brew tap majd/repo && brew install ipatool libimobiledevice ideviceinstaller

3. Токен станции из админки TakeSmart: **Приложения на iPhone → Добавить станцию**.
   Токен показывается один раз.
4. Сохранить настройки:

       python3 takesmart_station.py --setup --backend https://takesmart.ru --token ts_...

## Каждый день

    python3 takesmart_station.py

Откроется страница http://127.0.0.1:8765 (только на этом Mac). Дальше:

1. Подключить iPhone кабелем, разблокировать, на телефоне нажать «Доверять».
   Слева появится модель, версия iOS и число уже установленных приложений.
2. Покупатель вводит свой Apple ID и пароль, затем код подтверждения, который
   Apple пришлёт ему на устройства или по SMS. Пароль и код уходят напрямую
   в Apple с этого Mac — на сервер TakeSmart они не попадают и не хранятся.
3. Справа — вся история покупок аккаунта. Фильтр «Банки», поиск, галочка
   «Скрыть уже установленные». Отмечаем нужное → **Установить выбранные**.
4. Станция скачивает каждое приложение и ставит по кабелю, показывает ход
   по шагам. Чего нет в истории покупок — честно помечает «нет в покупках».
5. После установки станция сама выходит из Apple ID и удаляет скачанные файлы.
   Отключить автовыход: `--no-auto-logout`.

Внизу справа — «Поставить по App Store ID или Bundle ID» для случаев, когда
приложение не видно в списке, но точно покупалось.

## Что уходит на сервер

Раз в 2 секунды — пульс: версия станции, подключённый iPhone (модель, iOS),
есть ли вход в Apple ID и сколько покупок. По каждой установке — запись в
историю: какой телефон, какие приложения, версии, итог. Это видно в админке.

## Ограничения (объяснять покупателям)

- Ставится только то, что было в истории покупок именно этого Apple ID.
  Если банк никогда не скачивали на этот аккаунт — не появится.
- Версия — последняя, что была в App Store на момент удаления.
- Чужие («донорские») Apple ID не используем: при первом запуске приложение
  спросит код донора, а Apple ограничивает 10 устройств на аккаунт за 90 дней.
  Т-Банк сам выдаёт временный Apple ID — это их официальный путь.
- Пуш-уведомления у переустановленных приложений могут не приходить.

## Проверка без телефона

    python3 takesmart_station.py --simulate

Эмулирует iPhone и аккаунт с шестью покупками. В эмуляции пароль вида
`nocode…` пропускает шаг с кодом.

## Где что лежит

- Настройки: `~/Library/Application Support/TakeSmart Station/config.json`
  (адрес, токен, пароль файлового keyring для ipatool — права 600).
- Журнал: там же, `station.log`.
- Сессия ipatool: `~/.ipatool/` — очищается при выходе из Apple ID.

## Если что-то не так

- **Нет связи с админкой** — в шапке страницы будет текст ошибки сервера
  (например, «Админка не принимает токен станции» → создать станцию заново).
- **Не найдены утилиты** — команда `brew` выше; ipatool ставится из tap
  `majd/repo`.
- **iPhone не видно** — разблокировать телефон, переподключить кабель, нажать
  «Доверять». На macOS первое подключение может спросить разрешение.
- **Apple не принимает пароль** — у покупателя мог быть пароль приложения или
  включена блокировка аккаунта; проверить вход на appleid.apple.com.
