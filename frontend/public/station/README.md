# Помощник TakeSmart для iPhone (takesmart_station.py)

Маленькая программа для Mac в павильоне. Видит iPhone покупателя по кабелю и
умеет ставить на него приложения из истории покупок его Apple ID — в том числе
банки, которых больше нет в App Store. Вся работа идёт в админке TakeSmart,
раздел «Приложения»: там подключаете iPhone, покупатель вводит Apple ID, вы
отмечаете нужное и жмёте «Установить». Помощник — только исполнитель.

## Настройка Mac (один раз)

1. Утилиты (Терминал):

       brew tap majd/repo && brew install ipatool libimobiledevice ideviceinstaller

2. Скачать помощник и включить автозапуск (Терминал):

       curl -fsSL https://takesmart.ru/station/takesmart_station.py -o ~/takesmart_station.py && python3 ~/takesmart_station.py --autostart

   Помощник стартует сам при входе в macOS и работает в фоне. Обновить его —
   та же команда.

3. Открыть админку TakeSmart → «Приложения» на этом же Mac. Раздел сам увидит
   помощника и привяжет его (адрес админки и токен уходят помощнику по
   локальной сети, вручную ничего вписывать не нужно). Если браузер спросит
   про доступ к локальной сети — разрешить.

## Как это работает

- Покупатель вводит Apple ID, пароль и код прямо на странице раздела. Всё уходит
  с этого Mac напрямую в Apple (ipatool) — на сервер TakeSmart не попадает.
- Список — история покупок аккаунта для iPhone. Приложения скачиваются
  оригинальным файлом Apple по их App Store ID и ставятся по кабелю
  (ideviceinstaller). Что не куплено на этот Apple ID — «нет в покупках».
- После установки помощник сам выходит из Apple ID и удаляет скачанные файлы.
- На сервер уходят только пульс (модель iPhone, версия iOS, есть ли вход) и
  история установок — она видна в разделе.

## Ограничения (объяснять покупателям)

- Ставится только то, что было в истории покупок именно этого Apple ID.
- Версия — последняя, что была в App Store на момент удаления.
- Чужие «донорские» Apple ID не используем: при первом запуске приложение
  спросит код донора, а Apple ограничивает 10 устройств на аккаунт за 90 дней.
- Пуш-уведомления у переустановленных приложений могут не приходить.

## Команды

    python3 ~/takesmart_station.py --autostart        включить автозапуск и запустить
    python3 ~/takesmart_station.py --stop-autostart   выключить автозапуск и остановить
    python3 ~/takesmart_station.py                    запустить вручную (если автозапуск выключен)
    python3 ~/takesmart_station.py --simulate         проверка без телефона (эмуляция iPhone и покупок)

Страница помощника (запасной вход, если браузер не пускает админку к
127.0.0.1): http://127.0.0.1:8765 — там та же консоль.

## Где что лежит

- Настройки: `~/Library/Application Support/TakeSmart Station/config.json`
  (адрес админки, токен, пароль файлового keyring для ipatool; права 600).
- Журналы: там же `station.log` и `autostart.log`.
- Автозапуск: `~/Library/LaunchAgents/ru.takesmart.station.plist`.
- Сессия ipatool: `~/.ipatool/` — очищается при выходе из Apple ID.

## Если что-то не так

- **Раздел пишет «Запустите помощник»** — проверьте автозапуск командой выше
  или посмотрите `autostart.log`. Помощник запущен, но раздел его не видит —
  браузер не пускает страницу к 127.0.0.1: разрешите доступ к локальной сети
  или откройте http://127.0.0.1:8765.
- **«Не найдены утилиты»** — команда `brew` выше; ipatool ставится из tap
  `majd/repo`.
- **iPhone не видно** — разблокировать телефон, переподключить кабель, нажать
  «Доверять».
- **Apple не принимает пароль** — у покупателя мог быть пароль приложения или
  блокировка аккаунта; проверить вход на appleid.apple.com.
